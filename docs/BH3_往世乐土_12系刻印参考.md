## 1. 系统结构与解锁路径

### 1.1 一局里的刻印来源

1. **战斗层**：清怪后出现 3 个「门」，每个门对应一个刻印系，进入后可抽该系的刻印。
2. **商店层**：用银币买刻印/升级/追忆之证/特殊增益。
3. **双倍层**：奖励翻倍（双倍层常见于第 5、11 层等），是凑核心的关键窗口。
4. **追忆之证**：携带后改变刻印获取（例如「其将舍弃」使救世刻印初始等级 +1）。
5. **角色专属（真我）**：对应女武神才能抽到，见第 3 节。

### 1.2 解锁路径（核心规则）

```
普通刻印 ×3（同一系）  ──►  解锁该系「核心刻印」（2 选 1）
                              │
                              ▼
                        已持有某核心  ──►  该核心的「增幅刻印」（3 枚）开始可出
```

- **核心解锁条件**：集齐 **3 枚同系普通刻印**，且**第 3 枚必须在战斗层获得**（商店/其他途径补的第 3 枚不算触发）。
- **核心二选一**：每系有 2 个核心，只能拿 1 个；拿了 A 核心后，B 核心的 3 枚增幅不再生效/不再刷新（常见"二选一"锁定）。
- **增幅出现条件**：持有该系核心后，**再次进入同系门并选择同系刻印**时，才有机会抽到该核心对应的 3 枚增幅。
- **等级**：普通刻印可升级（+1/+2/+3），核心/增幅多数只有 0 级或独立档位；升级靠重复获取或商店。
- **重置与刷新**：商店可刷新；部分追忆之证/关卡效果提供额外刷新次数（8.x 起每层可刷新 1 次）。

### 1.3 数量核对

| 层级 | 每系数量 | 12 系合计 |
|---|---|---|
| 普通（基础 3 + 副 3） | 6 | 72 |
| 核心（二选一） | 2 | 24 |
| 增幅（每核心 3 枚） | 6 | 72 |
| **合计** | **14** | **168** |

## 3. 【真我】刻印的设计逻辑

### 3.1 它是什么

【真我】= 爱莉希雅的刻印，但在玩法上**不是第 13 条通用树，而是"角色专属刻印"**：

- **每个可出战女武神都有自己的一套「真我」刻印，固定 5 枚**，例如：
  - 真我·人之律者：【初见】【初绽】【初醒】【初程】【初念】的祝福
  - 空之律者：【律令】【空棘】【蔑尽】【虚界】【内能】的祝福
- **只有对应角色才能拿到/生效**，不进入通用池；别的角色抽到也无意义。

### 3.2 设计逻辑（三条）

1. **不做数值，改机制**：12 系通用刻印做的是"加伤害/加防御/加资源"，真我刻印做的是"改写角色本体的循环"——形态切换、蓄力、闪避、必杀衔接、资源（律者能量/水晶冰镜等）。它让角色在乐土里"变成另一个自己"，而不是"数值更高的自己"。
2. **5 枚 = 一条完整 Build 骨架**：通常覆盖启动（进场/形态）、循环（普攻/蓄力/闪避）、爆发（必杀/特殊攻击）、续航（回能/冷却）、质变（第 5 枚把前四枚串起来）。拿到 2–3 枚即可成型，5 枚全拿是"完全体"。
3. **与通用刻印正交**：真我不提供通用属性，所以"真我负责角色机制、通用负责数值与场景"，两者相乘。乐土高难的标准思路就是"先拿 3 枚真我定骨架，再用 12 系补数值/穿透/生存"。

### 3.3 获取路径（与通用刻印的差别）

- 开局第 1 层可额外选一次「角色专属刻印」（真我）；
- 部分关卡效果/追忆之证使"双倍层必出真我"（如携带特定追忆之证在第 5 层换装）；
- 商店与部分增益可再提供真我；
- 真我**不参与**"3 普通解锁核心"的通用规则，也没有核心/增幅层级——5 枚平级。

### 3.4 对本 mod 的启示

本 mod 旧实现把"真我"做成"国家定制刻印"（如德国「真我·日耳曼尼亚」），本质正确：**真我 = 势力专属机制改写，而不是再开一条通用树**。重写时建议：

- 12 系通用刻印 → 全局可获取的"通用增益池"；
- 真我 → 按国家 tag 定制的"国策式机制"（德国闪击节奏、苏联纵深、美国工业…），每个 tag 5 枚、平级、不进通用池；
- 获取入口：特殊项目解锁后，真我通过"国家任务链/决议"发放，通用刻印通过无瑕之钥抽取。

## 4. HOI4 落地建议

### 4.1 结构映射

| 游戏概念 | HOI4 实现 |
|---|---|
| 刻印系（12 系） | 12 条"刻印树"，每树 14 个节点（6 普通 + 2 核心 + 6 增幅） |
| 抽刻印（门） | 决议/事件三选一（加权随机），消耗无瑕之钥或行动点 |
| 3 普通 → 核心 | 用 dynamic modifier 或 country flag 计数：同系普通 ≥3 时解锁核心决议 |
| 核心二选一 | 二选一决议，选中后另一核心的增幅决议永久隐藏（flag 锁定） |
| 增幅 | 需持有对应核心 flag 才显示/可用 |
| 真我 | 国家专属决议链（5 枚，平级） |
| 刻印升级（+1/+2/+3） | 重复抽取或消耗资源升级，改 dynamic modifier 数值 |

### 4.2 数值预算建议

- **普通刻印**：单项 +0.5% ~ +2%（HOI4 里 1% 已经很值钱），或 +2% ~ +5% 条件型；
- **核心刻印**：给"机制型"增益（条件触发、资源转换），单项 +2% ~ +5%，并附带一个开关型效果；
- **增幅刻印**：给"质变"，条件化 +5% ~ +10%，或改变某条规则（如"战时才生效""战斗中叠加"）；
- **真我**：一国 5 枚，合计约等于"一条小国策树"的强度，避免与通用池叠加爆表。
