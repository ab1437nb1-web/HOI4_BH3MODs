本文件第 2 节的效果文本**逐条取自米哈游官方百科「圣芙蕾雅档案馆」**（12 个刻印词条页），属于游戏内文本：

## 1. 系统结构与解锁路径

### 1.1 一局里的刻印来源

1. **战斗层**：清怪后出现 3 个「门」，每个门对应一个刻印系，进入后可抽该系的刻印。
2. **商店层**：用银币买刻印/升级/追忆之证/特殊增益。
3. **双倍层**：奖励翻倍（双倍层常见于第 5、11 层等），是凑核心的关键窗口。
4. **追忆之证**：携带后改变刻印获取（例如「其将舍弃」使救世刻印初始等级 +1）。
5. **角色专属（真我）**：对应女武神才能抽到，见第 3 节。

### 1.2 解锁路径（核心规则）

```
普通刻印 ×3（同一系）  ──►  解锁该系「核心刻印」（2 选 1）
                              │
                              ▼
                        已持有某核心  ──►  该核心的「增幅刻印」（3 枚）开始可出
```

- **核心解锁条件**：在战斗层（**含双倍层**）拿完一枚普通刻印后，只要**同系普通刻印数 ≥ 3** 即可选核心——不要求恰好 3 枚，多拿的普通刻印不影响解锁；商店/其他途径补到的第 3 枚不计入「战斗中触发」。
- **核心二选一**：每系有 2 个核心，只能拿 1 个；拿了 A 核心后，B 核心的 3 枚增幅不再生效/不再刷新（常见"二选一"锁定）。
- **增幅出现条件**：持有该系核心后，**再次进入同系门并选择同系刻印**时，才有机会抽到该核心对应的 3 枚增幅。
- **等级**：普通刻印可升级（+1/+2/+3），核心/增幅多数只有 0 级或独立档位；升级靠重复获取或商店。
- **重置与刷新**：商店可刷新；部分追忆之证/关卡效果提供额外刷新次数（8.x 起每层可刷新 1 次）。

### 1.3 数量核对

| 层级 | 每系数量 | 12 系合计 |
|---|---|---|
| 普通（基础 3 + 副 3） | 6 | 72 |
| 核心（二选一） | 2 | 24 |
| 增幅（每核心 3 枚） | 6 | 72 |
| **合计** | **14** | **168** |

## 3. 【真我】刻印的设计逻辑

### 3.1 它是什么

【真我】= 爱莉希雅的刻印，但在玩法上**不是第 13 条通用树，而是"角色专属刻印"**：

- **每个可出战女武神都有自己的一套「真我」刻印，固定 5 枚**，例如：
  - 真我·人之律者：【初见】【初绽】【初醒】【初程】【初念】的祝福
  - 空之律者：【律令】【空棘】【蔑尽】【虚界】【内能】的祝福
- **只有对应角色才能拿到/生效**，不进入通用池；别的角色抽到也无意义。

### 3.2 设计逻辑（三条）

1. **不做数值，改机制**：12 系通用刻印做的是"加伤害/加防御/加资源"，真我刻印做的是"改写角色本体的循环"——形态切换、蓄力、闪避、必杀衔接、资源（律者能量/水晶冰镜等）。它让角色在乐土里"变成另一个自己"，而不是"数值更高的自己"。
2. **5 枚 = 一条完整 Build 骨架**：通常覆盖启动（进场/形态）、循环（普攻/蓄力/闪避）、爆发（必杀/特殊攻击）、续航（回能/冷却）、质变（第 5 枚把前四枚串起来）。拿到 2–3 枚即可成型，5 枚全拿是"完全体"。
3. **与通用刻印正交**：真我不提供通用属性，所以"真我负责角色机制、通用负责数值与场景"，两者相乘。乐土高难的标准思路就是"先拿 3 枚真我定骨架，再用 12 系补数值/穿透/生存"。

### 3.3 获取路径（与通用刻印的差别）

- 开局第 1 层可额外选一次「角色专属刻印」（真我）；
- 部分关卡效果/追忆之证使"双倍层必出真我"（如携带特定追忆之证在第 5 层换装）；
- 商店与部分增益可再提供真我；
- 真我**不参与**"3 普通解锁核心"的通用规则，也没有核心/增幅层级——5 枚平级。

### 3.4 对本 mod 的启示

本 mod 旧实现把"真我"做成"国家定制刻印"（如德国「真我·日耳曼尼亚」），本质正确：**真我 = 势力专属机制改写，而不是再开一条通用树**。重写时建议：

- 12 系通用刻印 → 全局可获取的"通用增益池"；
- 真我 → 按国家 tag 定制的"国策式机制"（德国闪击节奏、苏联纵深、美国工业…），每个 tag 5 枚、平级、不进通用池；
- 获取入口：特殊项目解锁后，真我通过"国家任务链/决议"发放，通用刻印通过无瑕之钥抽取。

## 7. 战斗内“持续伤害 / 无视防御”的 HOI4 机制考证

> 目的：判断能否用「近地支援机（CAS）持续伤害」承载【旭光】的撕裂与【救世者·凯旋】的无视防御。
> 结论先说：**CAS 通道做不到“持续”，也不允许无飞机注入；但 damage_units 可以完整复刻它的伤害性质。**

### 7.1 CAS 在 HOI4 里的真实规则

| 规则 | 数值 / 行为 | 来源 |
|---|---|---|
| 每场战斗的 CAS 上限 | **3 × 敌方已投入战斗宽度 × 地形修正**（例：森林 20 宽 → 54 架） | HOI4 Wiki, Air missions |
| 友军攻击加成 | 基础 +25%，按“实际参战 CAS / 上限”线性缩放 | 同上 |
| 对敌伤害 | ground_attack × 参战飞机数 次攻击，**随机选中一个敌师**；**无视防御、硬度、装甲** | 同上 |
| 伤害系数 | org 0.035 / str 0.035（陆战对陆战为 0.053 / 0.06） | 同上 |
| AA 减免 | 最高 75%（平均 AA 攻击 4.3 即满），另有 7% 概率击落（0.5% × 对空攻击） | 同上 |
| 结算周期 | **约每 8 小时一次**（HOURS_DELAY_AFTER_EACH_COMBAT = 4，双程往返按 ×2 计） | 游戏 defines + Wiki 例文 |
| 夜间 | 伤害 ×0.1（CAS_NIGHT_ATTACK_FACTOR = 0.1） | defines |
| 参战前提 | 机场在航程内、任务效率、燃料、不被拦截；地区制空影响效率 | Wiki |

关键点有两层：

1. **CAS 伤害是“脉冲式”**：飞机出动一次、打一轮，然后进入 4 小时（双程约 8 小时）冷却，不是逐小时连续生效。
2. **CAS 伤害没有脚本注入接口**：游戏没有“无飞机也能造成 CAS 伤害”的效果；想有 CAS 伤害就必须有真实 air wing、真实装备、真实航程与燃料。

所以「在特定战斗里持续造成近地支援伤害、还不让飞机退场」——**在 HOI4 的空中系统里不可能实现**；飞机的“退场/再出动”是引擎硬编码的循环。

### 7.2 但 CAS 的伤害性质可以被脚本复刻

damage_units（效果，任何 scope）能直接对指定 province / state / region 的部队造成 org / str 伤害：

    damage_units = {
      state = 5            # 或 province / region
      limit = { ... }      # 可加国家条件
      damage = 0.05        # 同时扣 org 与 str
      org_damage = 0.05
      str_damage = 0.05
      ratio = yes          # 按当前总量比例扣
      template = "xxx"     # 只打特定模板
      army = yes
    }

它与 CAS 的共同点正是我们要的：**直接扣 org/str，不经过“攻击 vs 防御/装甲”的结算**，因此天然“无视防御”。区别只是它不消耗飞机、不产生空战、也不受 AA/夜间/航程限制。

配套还可以用这些修饰符做“抗撕裂/减伤”类刻印：

| 修饰符 | 作用 |
|---|---|
| cas_damage_reduction | 降低受到的 CAS 伤害（可做“对空袭减伤”类刻印） |
| air_cas_efficiency / air_cas_present_factor | 提升/降低 CAS 参战效率 |
| air_close_air_support_org_damage_factor | 调整 CAS 对 org 的伤害 |
| org_damage_multiplier / str_damage_multiplier | 全局 org/str 伤害倍率 |

### 7.3 【旭光】撕裂的推荐实现

- **载体**：on_daily 脉冲 + damage_units，不需要任何飞机。
- **层数**：HOI4 没有“师级变量”，把层数放在**国家变量**（攻击方按目标国分别记，如 BH3_tear_stacks_GER）或**州变量**上；上限 70 层、每秒 25% 攻击力的原作数值改成“每层每天 X% org/str”。
- **作用范围**（三选一，按精度/性能取舍）：
  1. region（战略区）：最接近“整条战线持续受伤”，实现最简单；
  2. state（州）：更精确，但会把该州非参战部队也打进去；
  3. 国家级全境：最简单，数值必须压得很低，否则超模。
- **衰减**：撕裂层数按天衰减（subtract_from_variable），对应原作“10 秒持续”。
- **解锁联动**：核心「旭光，长明不落」把“每层撕裂”转成触发式爆发时，用 damage_units 一次性按层数结算即可。

### 7.4 【救世者·凯旋】“无视防御”的推荐实现

HOI4 的陆战伤害只有两个通道：常规战斗（攻击 vs 防御/装甲，受 defense、armor 影响）和**直接伤害**（CAS 与 damage_units）。没有“无视防御”这个修饰符，piercing 也不是可加的国家修饰符（它来自装备属性）。

因此：

- **推荐**：进入【救世之战】/首次命中时，触发一次 damage_units 的“真伤”爆发（按目标当前 org/str 的比例扣），表现“这一击无视防御”；之后再给一个短时 army_attack_factor 增益收尾。
- **不推荐**：用真实 CAS 去还原“无视防御”——会被 8 小时结算周期、制空、AA、夜间系数层层打折，最后只剩“偶尔炸一下”。
- 若要做“无视防御的持续压制”，把它做成 damage_units 的每日 tick，而不是 CAS。

### 7.5 一句话结论

| 需求 | 能否用 CAS 实现 | 正确做法 |
|---|---|---|
| 特定战斗中持续伤害（撕裂） | 不能（8 小时脉冲 + 必须有飞机） | damage_units + on_daily |
| 无视防御的一击（凯旋） | 部分能（但会被 AA/夜间/制空削弱） | damage_units 一次性真伤 |
| 空袭演出/统计 | 能 | 给 BHS 的空对地装备（已存在 BeinalesiBHS_air2ground，air_ground_attack = 350）单独做玩法，不与刻印机制耦合 |

### 7.6 本 mod 已有可直接复用的先例

不用从零试：仓库里已经跑通了同一套写法。

- common/scripted_effects/BH3_misc_scripted_effects.txt:134（休伯利安主炮）：
      damage_units = {
          state = BH3_Hyperion_pos
          org_damage = 15
          str_damage = 25
          ratio = no
          limit = { has_war_with = ROOT }
      }
- common/on_actions/BH3_on_action.txt:334 的 on_daily 里已有一日一拍的守卫：
      if = { limit = { NOT = { check_variable = { global.BH3_Hyperion_last_tick = global.date } } }
             set_variable = { global.BH3_Hyperion_last_tick = global.date } ... }

所以「撕裂」只需要：州变量定位 + on_daily 去重 + damage_units 按层数结算，改动量很小。

### 7.7 对两枚刻印的最终建议

## 8. 低组织度减伤与【浮生】「无敌」的写法

### 8.1 词条本体：org_loss_at_low_org_factor

这是 HOI4 里**唯一的“低组织度”修正**，官方本地化与定义都能对上：

| 项 | 内容 |
|---|---|
| 修饰符名 | org_loss_at_low_org_factor |
| 官方显示名 | Organization loss when below 25% |
| 触发阈值 | **最大组织度的 25%**（define ORG_UNIT_WEAK = 0.25） |
| 作用 | 战斗中、组织度低于 25% 时，组织度损失 × (1 + 数值) |
| 取值 | -1.0 = 不再损失组织度；-0.5 = 损失减半；正值 = 损失增加 |

写法（放进 idea / dynamic_modifier / 学说 / 将领特质都可以）：

    BH3_ER_Fusheng_recollection_idea = {
        modifier = {
            org_loss_at_low_org_factor = -0.5
        }
    }

动态修正里同样可用，并且能用国家变量做开关（仓库里已有同样写法）：

    BH3_ER_Fusheng_memory_dm = {
        icon = GFX_modifiers_BHSinvasion_effect
        enable = { check_variable = { BH3_ER_Fusheng_memory > 0 } }
        org_loss_at_low_org_factor = -1.0
    }

注意三个边界：**只减组织度损失、不减兵力（strength）**；**只在战斗中生效**；**阈值写死 25%**，脚本不能改成别的百分比。

### 8.2 与“无敌”直接相关的另外两个词条

| 修饰符 | 官方显示名 | 说明 |
|---|---|---|
| org_damage_multiplier | Organization Damage Taken | 受到的**组织度伤害**倍率（负数=减伤，-1.0=不吃组织度伤害） |
| str_damage_multiplier | Strength Damage Taken | 受到的**兵力伤害**倍率（负数=减伤，-1.0=不吃兵力伤害） |
| cas_damage_reduction | —— | 只对 CAS 伤害生效（最高 100%），不影响陆战与脚本伤害 |

这两个倍率是**国家级修正**（原版用于“强行进攻 / 死守”这类指挥官技能：强行进攻 = 组织度不掉、兵力伤害 +60%），语义来自官方本地化 Organization/Strength Damage Taken。

相关引擎常数（不可脚本修改）：

- COMBAT_LOW_ORG_HIT_CHANCE_PENALTY = -0.5：组织度极低时命中率惩罚；
- LOW_ORG_FOR_ATTACK = 0.3：组织度低于 30% 时进攻移动减速。

### 8.2.1 实测记录（2026-11-25，测试 mod：tools/BH3_modtest）

| 层级 | 写法 | 结果 |
|---|---|---|
| 国家精神（ideas） | str_damage_multiplier = -1.0 + org_damage_multiplier = -1.0 | **无效**。精神 tooltip 能显示“受到的组织度损失 -100.0% / 受到的兵力损失 -100.0%”，但实战中部队照常掉组织度与兵力（战力 99%） |
| 国家精神 | -0.5 / 单变量 / +1.0 对照 | 一并待测（同一批精神都在测试 mod 里） |
| 指挥官技能（unit_modifiers） | 同上 | **待测**（v2 已加入 5 个测试技能，见 README 第六节） |

结论（国家层级）：这两个 modifier 在 ideas 里是“能解析、不生效”，属于**作用域不对**，不是拼写或本地化问题。
原版它们只出现在指挥官技能的 unit_modifiers 里，所以真正的验证必须放到技能上做。

### 8.3 【浮生】两个核心的落地配方

原作：

- 「浮生历历，百态无常」= 每 10 秒 1 层【战士的决意】（上限 6 层），被击中时减 1 层抵消本次伤害，并对周围造成剩余层数 ×650% 伤害；
- 「浮生茫茫，百态皆苦」= 初始 6 层【战士的回忆】，持有期间普通刻印直接满层，被击中减 1 层抵消伤害并无敌 0.5 秒。

HOI4 侧把“层数”放在国家变量上（BH3_ER_Fusheng_memory），用动态修正做护盾：

| 方案 | 写法 | 表现 |
|---|---|---|
| A. 低组织护盾（推荐，最稳） | org_loss_at_low_org_factor = -1.0 + org_damage_multiplier = -0.35 | 组织度低于 25% 后不再掉组织、且平时少吃 35% 组织伤害 —— “打不溃” |
| B. 真无敌（需实测） | str_damage_multiplier = -1.0 + org_damage_multiplier = -1.0 | 层数 > 0 时几乎不吃任何战斗伤害；层数归零移除修正即“破盾” |
| C. 对脚本伤害的免疫 | 所有 damage_units 结算前判断 limit = { NOT = { check_variable = { BH3_ER_Fusheng_memory > 0 } } } | 撕裂、主炮、核弹等脚本伤害被层数完全吸收 |

建议**A + C 组合**：引擎战斗伤害用 modifier 软化，mod 自己造的脚本伤害用层数精确拦截；B 方案虽然最像“无敌”，但 -1.0 是否被引擎钳制、与 CAS 伤害如何叠加要进游戏实测（文档没有写 clamp 规则）。

### 8.4 用变量直接驱动减伤幅度

动态修正的修正值可以取自变量（原版注释：max_fuel = var_max_fuel），所以“每层减伤 X%”可以直接写成：

    BH3_ER_Fusheng_memory_dm = {
        enable = { check_variable = { BH3_ER_Fusheng_memory > 0 } }
        org_damage_multiplier = BH3_ER_Fusheng_org_neg      # 负值变量，如 6 层 = -0.6
        str_damage_multiplier = BH3_ER_Fusheng_str_neg
    }

层数变化时只需改这两个变量，修正即时生效——比“每层一个动态修正”干净得多。

## 9. 刹那一刀「樱上幕」的实现考证

原作效果（lv0，官方词条）：

> 【樱幕结界】未开启期间累计触发 3 次极限闪避技能后，开启【樱幕结界】静止所有敌人 3 秒，结束后对所有敌人造成期间受到伤害 40% 的生命流失效果。若角色具有【时空】特性，则角色触发全局时空时，自身获得 35% 的物理穿透和 20% 的元素穿透，持续 8 秒，重复触发刷新。

拆成四个要素，逐一对照 HOI4 的能力边界：

| 原作要素 | HOI4 有没有对应物 | 结论 |
|---|---|---|
| 累计 3 次极限闪避 | 陆军没有闪避/命中率属性 | 只能用“事件/每日”代理计数 |
| 静止所有敌人 3 秒 | 没有时停；最小时间粒度是天（timed idea）或小时（指挥官技能 duration） | 3 秒 → 1 天（或 72 小时的技能） |
| 期间受到伤害的 40% 转生命流失 | 无法读取部队在窗口内吃到的伤害（没有师级 org/str 触发器，也没有受击事件） | 只能用“固定比例”近似 |
| +35% 物穿 / +20% 元素穿 | 没有穿透类国家修饰符（piercing 来自装备） | 用攻击 / damage_units 近似 |

### 9.1 推荐路线：决议触发 + timed idea + 延迟事件

第一步：攒“闪避”层数。

原版没有闪避，最省事且可调的代理是每日概率累加（也可换成 on_army_leader_won_combat 的“防守获胜”语义）：

    # on_actions 的 on_daily 里
    if = {
        limit = { has_war = yes }
        if = {
            limit = {
                check_variable = { BH3_ER_setsuna_dodge < 3 }
                random < 0.5          # 可调：每 2 天平均 +1
            }
            add_to_variable = { BH3_ER_setsuna_dodge = 1 }
        }
    }

第二步：开结界（3 层满 → 决议出现 → 点击/自动执行）。

    # 决议 complete_effect
    clr_variable = BH3_ER_setsuna_dodge
    add_timed_idea = { idea = BH3_ER_sakuragi_self days = 3 }
    every_enemy_country = {
        add_timed_idea = { idea = BH3_ER_sakuragi_enemy days = 3 }
    }
    country_event = { id = BH3_ER.sakuragi_settle days = 3 }

两条 timed idea 的修饰符：

    # 我方：结界护体（“敌人打不到你”的近似）
    BH3_ER_sakuragi_self = {
        modifier = {
            str_damage_multiplier = -0.5
            org_damage_multiplier = -0.5
            army_speed_factor = 0.2
        }
    }

    # 敌方：被“静止”（打不动、跑不了）
    BH3_ER_sakuragi_enemy = {
        modifier = {
            army_speed_factor = -0.9
            breakthrough_factor = -0.3
            army_attack_factor = -0.25
        }
    }

第三步：结算（3 天后的延迟事件）。

HOI4 读不到“窗口内受到多少伤害”，只能按比例近似。建议在敌方 scope 对交战州做一次 damage_units：

    BH3_ER.sakuragi_settle = {
        is_triggered_only = yes
        option = {
            name = BH3_ER.sakuragi_settle.a
            every_enemy_country = {
                damage_units = {
                    state = 目标州变量
                    org_damage = 0.15     # 平衡值，不是原作 40%
                    str_damage = 0.15
                    ratio = yes
                    limit = { has_war_with = ROOT }
                }
            }
        }
    }

第四步：【时空】特性 → 穿透。

没有穿透修饰符，用攻击/真伤近似即可：

- 给己方 timed idea：army_attack_factor = 0.35（8 秒在 HOI4 里就是 1 天）；
- 或直接给一次 damage_units 的“真伤”爆发，表现“穿透”。

### 9.2 备选路线：自定义指挥官技能（ability）

原版 common/abilities 下的技能支持 duration（单位：小时）与 unit_modifiers，last_stand 就是现成模板（duration = 168 小时、org_damage_multiplier = -1.0、cannot_retreat_while_defending = 1.0）。

可以照抄做“樱幕结界”技能：

    BH3_ER_ability_sakuragi = {
        name = ABILITY_BH3_SAKURAGI
        type = army_leader
        cost = 0.2
        duration = 72                     # 72 小时 = 3 天
        unit_modifiers = {
            org_damage_multiplier = -1.0  # 结界内不掉组织度
            str_damage_multiplier = -0.4
            defence = 0.3
        }
    }

优点：时间粒度到小时、只作用于该将领麾下的部队、UI 与冷却都是现成的。

缺点更关键：技能到期没有回调，做不了“结束时结算反伤”；而且它的开启条件是指挥点，不是“3 次闪避”。

### 9.3 结论

| 方案 | 能做到 | 做不到 |
|---|---|---|
| 决议 + timed idea + 延迟事件（推荐） | 3 层计数、结界减伤/减速、延迟结算、与刻印树联动 | 精确 3 秒、精确“期间伤害 40%” |
| 指挥官技能 | 小时级结界、只影响该将领部队 | 结束结算、与“闪避”计数联动 |

落地建议：用决议方案，把“3 秒”文案改写成“1 次战斗结算窗口”，“40% 反伤”改成按敌方当前 org/str 的固定比例（先 10%~15% 起步，再平衡）。这样既保留“攒 3 层 → 开结界 → 反伤”的原作节奏，又完全落在 HOI4 已有的能力范围内。

### 9.4 顺带可复用的两个原版机制

- on_army_leader_won_combat（ROOT 为将领、FROM 为国家）：可在“防守获胜”时 +1 闪避层，比纯随机的每日累加更有“闪避成功”的语义；
- fighting_army_strength_ratio（国家触发器）：可比较双方“正在交战部队”的强度比，用来判断“这一战值不值得开结界”。
