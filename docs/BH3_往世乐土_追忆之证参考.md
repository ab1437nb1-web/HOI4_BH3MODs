# 往事乐土 · 追忆之证参考

> 结论先行：**米哈游官方百科（圣芙蕾雅档案馆）的「追忆」栏目只有 13 篇剧情，没有追忆之证的数值效果。**
> 本文件把官方剧情页全部收录，并用攻略站补齐 4★ 追忆之证的效果摘要，同时标注可信度与缺口。

---

## 0. 官方站点里到底有什么

| 栏目 | 内容 | 有无数值效果 |
|---|---|---|
| 刻印 | 12 系通用刻印，每系 14 枚（见另一份参考） | 有（lv0~lv3 全文） |
| 追忆 | 13 篇英桀剧情（本文件第 1 节） | **没有**，纯剧情文本 |
| 角色 | 各女武神【乐土出战 / 乐土支援】页 | 有角色数据，无追忆之证 |
| 事件 | 乐土事件 | —— |

实测抓取：13 篇追忆页全文里「效果」「冷却」「充能」「伤害」等关键词出现次数为 0~3，且都是剧情用词，没有一条道具数值。

所以「追忆之证的效果」只能从攻略站补，且只能到「摘要级」，达不到刻印那种逐条原文的精度。

### 命名对照（容易混）

游戏里 4★ 追忆之证用的是**诗意名**，不是刻印系名。攻略与玩家常用系名指代，例如：

| 官方名 | 对应 |
|---|---|
| 其将舍弃 | 凯文 / 救世系（+1 救世刻印等级等） |
| 狂王的面具 | 千劫 / 鏖灭系 |
| 因你而存在的故事 | 爱莉希雅 / 真我系（开局多拿专属刻印） |

完整对照表官方百科没有收录，需要游戏内道具图鉴补齐。

## 3. 追忆之证的通用机制（据攻略与游戏常识）

- 每局可携带 **2 件**追忆之证，可在休息层商店更换；
- 分 3★ / 4★ 两档，4★ 多为「主动助战技能」（充能 → 释放），3★ 多为被动/剧情向；
- 效果类型：直接伤害、增益（全伤/生命上限/无敌）、资源（银币/SP）、刻印强化（+1 刻印等级、开局多拿专属）；
- 部分追忆之证与特定刻印系绑定（如鏖灭系配狂王的面具），换系时要一起换。

## 4. 对 HOI4 的映射建议

| 原作机制 | HOI4 可实现方式 |
|---|---|
| 携带 2 件、休息层可换 | 国家精神槽 2 个 + 商店决议（花银币/政治点替换） |
| 4★ 的「充能 → 主动释放」 | 指挥官技能（已验证可用的通道：unit_modifiers + duration/cooldown） |
| 3★ 的被动增益 | 国家精神 / 动态修正（普通国家修正，如 army_attack_factor，国家级有效） |
| 刻印强化（+1 等级、开局多拿专属） | 抽刻印决议里的权重/初始等级变量 |
| 银币经济（空梦摇摇乐） | 现有银币变量的赌博决议，注意加上限与冷却 |

注意：**damage_taken 类修正（str/org_damage_multiplier）只能在指挥官技能里生效**（见主参考文档 §8 实测），所以 4★ 里「无敌/减伤」型追忆之证要按技能做，不能按国家精神做。

## 5. 数据缺口

1. 官方百科的 13 篇追忆是剧情页，**没有道具数值**；
2. 4★ 效果只有攻略摘要（本文件第 2 节），没有逐条原文；
3. 3★ 追忆之证与角色专属追忆之证，官方百科与主流攻略站都没有系统收录；
4. 官方名 ↔ 刻印系的完整对照表缺失。
