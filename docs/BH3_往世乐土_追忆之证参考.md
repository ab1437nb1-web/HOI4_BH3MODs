# 往事乐土 · 追忆之证参考（官方物品词条）

> 数据来源：米哈游官方百科「圣芙蕾雅档案馆」→ 往世乐土 → 物品（channel/map/22/33），逐个道具词条页抓取。
> 与游戏内文本一致；**所有条目都没有“受到伤害倍率 / damage_taken”类字段**，效果都是刻印强化、充能技能、属性增益或传送锚点概率。

抓取结果：该分区共 **50 个词条**，其中 **45 个追忆之证**（1★ 6 / 2★ 13 / 3★ 12 / 4★ 14）+ **5 个材料**（无瑕之钥、闪亮的银币等）。

---

## 0. 机制速览

| 项 | 内容 |
|---|---|
| 携带 | 每局 2 件，可在休息层商店更换（部分道具会锁死更换，如「荆棘花冠」「故土难归」） |
| 稀有度 | 1★ 通用属性 / 2★ 传送锚点概率 / 3★ 刻印系强化 / 4★ 充能主动技能（附带 +1 刻印等级） |
| 充能 | 多数 4★ 需要充能到 600 才能释放；充能方式各异（必杀、武器技、闪避、击杀、受伤等） |
| 效果类型 | 刻印初始等级 +1、核心刻印条件放宽、传送锚点概率提升、主动技能（伤害/增益/控制）、通用属性 |
| 无伤害倍率 | 全部 45 条的文本里都没有“受到伤害 -X% 倍率”这类字段；减伤是直接写数值（如白铁酒壶“受到的全伤害减少30%”） |

## 7. 对 HOI4 的映射建议

| 原作 | HOI4 实现 |
|---|---|
| 2 件携带位、商店更换 | 2 个国家精神槽 + 商店决议（花银币/政治点替换） |
| 4★ 充能 600 → 主动技能 | 指挥官技能（已验证通道：unit_modifiers + duration/cooldown）；充能用国家变量累加，600 时解锁技能 |
| 3★ 刻印 +1 级、核心条件放宽 | 抽刻印决议的权重/等级变量；核心解锁条件判断里加“是否持有该 3★” |
| 2★ 锚点概率 | 抽卡决议的随机权重（按系加权） |
| 1★ 通用属性 | 精神 modifier（army_defence_factor、max_organisation 等，国家级有效） |
| 材料（无瑕之钥/银币） | 现有资源系统，无需新增 |

注意：减伤类若要走 str/org_damage_multiplier，只能放在指挥官技能的 unit_modifiers 里（见主参考文档 §8 实测）；写成国家精神或 1★ 道具会“显示但不生效”。
