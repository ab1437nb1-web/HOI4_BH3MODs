# 空中女武神装甲（空战型）数值模板

游戏内数值以 txt 为准；本文件记录依据、推导与验证。

## 一、参考依据与已确认的决定

1. **5 代划分 + 不可设计的律者级**：第一代 / 第二代 / 第三代 = 有预设设计（领域装·白练 / 天穹游侠 / 白骑士·月光）；第四代 / 次时代 = 仅底座数据；其上是不可设计的**律者级**顶格。
2. **定价基准 = 陆战女武神"营"的造价**；"女武神作战人员"由决议发放、不计成本，只限制数量上限。
3. **mod 自带的空中单位（贝纳勒斯等）是入侵模式赠送单位，不作定价依据**。
4. **性价比必须与原版拉开差距**：每代 ≥ 原版同级 2.7 倍，且逐代不下降。
5. **按空战 / 陆战公式校核**（用户提供 wiki 公式）：不能只看攻防；机动与速度各有硬上限；配件应做成"固定值 + 百分比"（对齐陆战模块写法），并适当削弱底盘。

## 二、两套公式给出的属性价值与上限

### 空战（"Air combat"）

```
伤害(击落架数) = max( (基数 − 机动减免 + 相对速度加成 + 绝对速度加成) × 0.01 / 防御 , 0.01 )
基数 = 出击机数 × 0.2 × 攻击        (COMBAT_DAMAGE_STATS_MULTILPIER = 0.2)
机动减免 ≤ 基数 × 1.35   （敌我机动比封顶 4 倍）
相对速度加成 ≤ 基数 × 1.625（速度比封顶 3.5 倍）
绝对速度加成 ≤ 基数 × 0.2（速度按 800 封顶）
```

| 属性 | 作用 | 上限 | 本设计 |
|---|---|---|---|
| 对空攻击 | 伤害基数乘数；出击顺序、护航(÷100)、反扰乱(÷200) | 无 | 全力拉高 |
| 对空防御 | 伤害除数 | 无 | 全力拉高（最值钱） |
| 对空机动 | 减免受到的伤害 | 比值 4 倍 | 只拉到 260~420（对原版与 mod 内敌方均已吃满） |
| 最大速度 | 相对/绝对速度加成；扰乱、护航 | 比值 3.5、绝对项 800 | 3.5× 原版同代（1400~5000） |
| 出击机数 | 直接进伤害基数；3 倍多机上限、探测 | — | 联队 50 架（律者级 25 架） |

### 陆战（"Land battle"）

```
攻击次数 = round(硬度修正后攻击 ÷ 10)；防御次数 = round(防御 ÷ 10)
命中率 = 10%（防守方尚余防御次数） / 40%（防御次数耗尽）
组织度伤害 = 骰值 × 0.053（未穿透时骰由 2.5 升为 3.5）   ；HP 伤害 = 骰值 × 0.06
```

## 五、配件体系（43 个模块：固定值 + 百分比）

**结构原则（本轮按用户要求调整）**：
1. **推力全部绑定在驱动核心（引擎槽）上，机体本体不带推力** ✓（本体只带重量）。
2. **驱动核心 = 全局乘数**（对齐陆战引擎写法：陆战崩坏能驱动是乘全部战斗属性）。电力线保持"廉价、无全局乘数"的入门定位；核聚变与崩坏能给出全局乘数并附带可靠性代价。
3. **全部战斗模块同时给固定值与百分比**（44 个模块中 42 个带百分比，另 2 个是纯功能件），且**全部 44 个都带重量**。
4. **配件造价压到陆战比例**（底盘贵、配件便宜：陆战底盘 20~500 IC、配件 1~85 IC），否则配件占满造价、把整体性价比摊薄到原版以下（实算验证过）。
5. 底盘相应削弱 10%。

**推力与重量的设计（本轮按用户反馈调整）**：
- 原版引擎是"同代多种并联"：`engine_1_1x` 推力 11 → `2x` 19 → `3x` 23 → `4x` 32 → `6x` 41，最高 `engine_4_6x` **105**。原先的 12~45 偏保守，现按"**对标原版双引擎（2x）/ 四联（4x）档**"抬到 30~80（单发机型，不做 6x 档）。
- **全部 44 个模块都带重量**（原版同样是部分模块带重量：95 个模块里 45 个有 `weight`，取值 0~20）。
- 于是推力门槛成为真实设计约束：**第 1~3 代底盘（8/11/14）挂任何配件都够用；第 4 代（18）与第 5 代（24）挂满配件（约 +12.6）后分别需要推力 ≥32 / ≥37，入门引擎（30/34）不够**，必须换中高档——与原版"重机体必须换强引擎"的体验一致。
- **空中"崩坏能反应炉·改良"**：按陆战同名模块同步补上（陆战由特殊项目 `BH3_sp_ValkyrieArmor_Engine_HonkaiImproved` 解锁），空中版挂到同一项目；图标复用陆战 `BH3_ValkyrieArmor_Engine_HonkaiImproved.dds`。

**神之键的设计依据**：陆战中神之键即使到次世代也是决定性因素——固定值很大（+30~210）、专精化百分比（×0.85~×1.35，带负面）、并付可靠性代价，且需要特殊项目解锁。空中版照抄这一结构，数值按空中量级放大，并**挂到陆上同名神之键的特殊项目上**（`enable_equipment_modules` 追加），槽位上放进"特殊模块 1/2/3"（与陆战把神之键放进"额外装备"槽一致），且限制"神之键最多 2 个"。

### 侵蚀之律者：锚在崩坏侧刷怪机制上（本轮）

它不走常规科技树，而是挂在**崩坏方的降临流程**里：

- 科技 `Elysia_HerrscherofErosion_Research` 本身只由"我即崩坏"的**侵蚀律者降临效果**授予（`BH3_bhs_Invasion_scripted_effects.txt` 的侵蚀块）→ 在该科技的 `enable_equipments` 加空中装备 `_0`、`enable_subunits` 加 `HerrscherErosionElysiaAir`；
- 同一段降临效果里追加 `add_equipment_to_stockpile = { type = HerrscherErosion_Elysia_Air_equipment_0 amount = 2000 }`，与崩坏方既有单位 `BeinalesiBHS` 的发放方式完全一致（**先给科技、再给装备库存，AI 据此成军**）；
- 因此玩家侧既无法研发、也不会在正常对局的科技树/生产列表里看到它（该科技不在玩家科技树内）。

### 崩坏侧（"我即崩坏"）的同步机制（按用户说明补齐）

用户说明的三件事，逐一落到实现：

1. **崩坏侧共有 6 个 boss 生成块**（理 / 空 / 雷 / 死生 / 薪炎 / 侵蚀），陆上用 `set_technology` + `division_template` + `create_unit = { count = 1 }`，即**只能出 1 个**；"人之律者"不在其中（崩坏侧不刷它）。
2. **崩坏侧面板高于玩家侧**，靠 idea 里的 `equipment_bonus` **逐个点名装备变体**做即时强化（`instant = yes`）。`common/ideas/Benghuai_idea.txt` 中共 **5 个 idea** 点名律者装备，数值分三档：`BHS_herrscher_enhance_idea` 为 soft/hard +5（×6），`BHS_Benghuai_idea` / `BHS_Benghuai_idea_Player` / `BHS_level5_idea` 为 +1（×2），`BHS_level4_idea` 为 +0.5（×1.5）。
3. **给玩家设计的空中单位会同步到崩坏侧**：空中装备挂在同一批律者科技上，而入侵脚本会给崩坏方 `set_technology` 这些科技。

据此补齐两处：

| 项 | 做法 |
|---|---|
| boss 加成镜像 | 在上述 **5 个 idea** 里为每个律者装备补上对应的**空中装备条目**，数值取同一 idea 内陆战条目的镜像：陆战 `soft_attack`/`hard_attack` → `air_attack`、陆战 `defense` → `air_defence`、陆战 `breakthrough` → `air_agility`，共 **30 条（6 装备 × 5 idea）** |
| 空中 boss 只出 1 个 | 本版没有"直接创建联队"的脚本效果（无 `create_air_wing`），故在 6 个 boss 生成块里各加一条 `add_equipment_to_stockpile = { type = <X>_Air_equipment_0 amount = 25 }` —— **25 架 = 恰好 1 个 25 架联队**，对应陆上的 `count = 1` |

因此崩坏侧空中律者的实际面板约为玩家侧的 ×6 攻击 / ×3 防御 / ×3 机动（与陆上 boss 同比例），属"boss 强于玩家侧"的设计使然。后续要调空中 boss 强度，改这 30 条 idea 条目即可。

### 玩家侧 MIO：圣芙蕾雅学院（本轮补齐空军写法）

- MIO 级 `equipment_type` 含全部 6 个空中装备（可挂载）；**未纳入「侵蚀之律者」**（陆战名单里也没有它，属崩坏侧）；
- 改后每个空中律者的合计（买满 MIO 时）：**对空攻击 +100%**（与陆战软攻 +100% 持平）、空中防御 +25%~+45%、机动 +20%~+45%、最大速度 +15%~+35%、生产花费 −40%（各律者因自己的签名特质不同而有差异）。

### 玩家侧 MIO：赫尔海姆实验室（本轮一并补齐）

`BH3_MIO_Schicksal_Herheim_Lab` 管的是**可设计的女武神装甲**（`equipment_type = { BH3_ValkyrieArmor_classis }`），共 **12 个特质**。本轮把**可设计空中底盘 `BH3_ValkyrieAir_ala`** 加入其 `equipment_type` 与全部 12 个特质的 `limit_to_equipment_type`，并按与圣芙蕾雅完全相同的规则补齐空军数值：

- `air_attack` = 陆战 `soft_attack + hard_attack`（该特质若已有 `air_attack` 则保留原值）、`air_defence` = 陆战 `defense`、`air_agility` = 陆战 `breakthrough`（无则取 `ap_attack`）；
- **负值同样镜像**：「更多产量1/2」的降硬攻/降突破/降防御，对空中同样生效（`air_attack`/`air_defence`/`air_agility` 为负），保持"更便宜但更弱"的取舍，不出现只对陆战生效的单边削弱；
- `maximum_speed`、`build_cost_ic`、`reliability` 为同名属性，列进名单后自动生效；特质里的 `production_bonus`（生产效率/产能/成本）也随 `limit_to_equipment_type` 覆盖空中装备的生产；
- 「提高生产效率」只有 `production_bonus`、无 `equipment_bonus`，「加强机动性」只有 `maximum_speed`，均无需额外补空军数值。

同时把圣芙蕾雅学院里 3 处 `air_attack` 统一为"软攻+硬攻之和"（基础课程 0.1、最后一课 0.2、彼岸双生 0.15），两个 MIO 使用同一套镜像规则。

面板为满配次时代（129,329）的 **1.28~1.33 倍**，性价比 38.37~40.00 高于满配次时代的 28.01（约 **1.4 倍**）。

### 已修 bug（用户实测发现）

律者级原本写了 `weight = 28/30`，导致"实际重量超过推力、无法生产"。根因：**`thrust` 只由引擎模块提供，而不可设计装备没有引擎槽**；原版所有不可设计的空中装备（运输机、导弹等）以及本 mod 现有的 BHS 空中装备**都不写 `weight`**。现已删除该字段，与 mod 自身写法一致。

## 八、与陆上口径的比较（说明"空中是否过头"）

**方法修正（用户指出）**：原版步兵营软攻只有 3（`infantry_equipment` 的 `soft_attack = 3`），步兵主要提供 HP、组织度与防御，**攻击主要由装甲单位提供**，只用步兵比较有系统性误差。故改用截图中的 1 步兵营 + 1 中坦营混成师（软 55.8 / 硬 29.0 / 防御 36.8 / 突破 53.8 / HP 27 / 组织度 35 / 装甲 22 / 穿甲 72 / 宽度 4 / 造价约 301），按同战斗宽度放大到 20 宽。

| 战场 | 编成 | 造价比 | 我方打空对方 | 对方打空我方 | 时间比 | **时间比 ÷ 造价倍数** |
|---|---|---|---|---|---|---|
| 陆战 | 100 个女武神营 vs 5×(1 步兵 + 1 中坦)（各 20 宽度） | 1 : 21.2 | 0.4 小时 | 876 小时（36.5 天） | 2,190× | **≈103×** |
| 空战 | 50 架女武神联队 vs 100 架原版联队 | 1 : 3.2 | 约 15 次出击 | 5,000 次出击 | 333× | **≈104×** |

两条线的"统治力 ÷ 造价倍数"落在同一量级（103 vs 104），说明空中线的强度取向与陆上线一致。此前"与原版保持 2.7 倍"的线性指标会严重低估非线性效应（攻击是伤害乘数、防御是伤害除数、命中率 10%/40% 两档、HP 与组织度存在量级差）。
