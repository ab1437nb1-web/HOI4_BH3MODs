# HOI4_BH3MODs

《崩坏3：兵种+兵模》(HonkaiImpact3: units & models) 的**源码库**。

## 这个仓库是什么

只保存适合做版本管理的文本内容：脚本、事件、决议、本地化、界面定义和设计文档。

**不包含**贴图、音效、音乐、模型、动画和 PSD 工程文件，合计约 952 MB。这些文件按 `.gitignore` 的规则排除在版本管理之外，所以：

> **直接 clone 本仓库得到的不是一个能运行的 mod**，全部美术与音频资源都是缺失的。要实际游玩请在 Steam 创意工坊订阅本 mod。

## 关于 `descriptor.mod` 里的依赖列表

该文件声明了一批其他 mod。在 HOI4 社区的实际使用习惯中，这份列表更接近一种**兼容性适配**声明——用来说明本 mod 与哪些 mod 共存、以什么顺序加载——而不是「必须全部安装才能运行」的硬性前置条件。
